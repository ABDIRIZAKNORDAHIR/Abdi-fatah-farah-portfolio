# Abdi fatah farah — Portfolio

Complete local portfolio source with all five supplied photos embedded in `src/photos.ts`; separate image files are not required.

## Run locally
Requires Node.js 18 or newer. On Windows, double-click `run-local.bat`. Or open a terminal in this folder and run:
```sh
npm install
npm run dev
```
To create a production build, run `npm run build`.

Edit `src/portfolio-data.ts` to update portfolio content. Site structure is in `index.html`, interactions in `src/main.ts`, and responsive design in `src/styles.css`.

All five portraits are bundled in the source and display locally without any extra downloads. To create a ZIP after saving the folder to your computer, run `make-zip.ps1` in PowerShell.
